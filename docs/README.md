# MindForm — Documentation index

Welcome to the MindForm engineering documentation. The product docs for users
(MCP setup, Coach guide) live in the app under **/docs** — this folder is the
equivalent, plus the internal architecture and development guides.

## Repo layout (top level)

```
MindForm/
├── backend/               Express + Mongoose API (serves the built frontend in prod)
│   ├── public/            production build output of ../frontend (regenerated by `npm run build`)
│   └── src/
│       ├── config/        db.js — Mongo connection
│       ├── controllers/   auth, tasks, habits, goals, fapless, voice
│       ├── mcp/           MCP server: http.js (HTTP), tools.js (13 tools), server.js (stdio bridge)
│       ├── middleware/    auth (JWT), errorController
│       ├── models/        User, TaskWeek, HabitMonth, Goal, Fapless, ForumMessage, VoiceLog, MCPKey
│       ├── routes/        /api routers (+ routes/mcp.js — key management)
│       └── utils/         aura engine, AppError, catchAsync, email validator
├── frontend/
│   ├── public/            SEO assets: robots.txt, sitemap.xml, llms.txt/llms.md, site.webmanifest
│   └── src/
│       ├── api/           typed fetch client (timeouts, 401 handling)
│       ├── components/    Sidebar, Toast, ConfirmDialog, Footer, CodeBlock, MCPModal, Onboarding…
│       ├── context/       AuthContext
│       ├── hooks/         useSync (race-safe auto-save)
│       ├── lib/           nav.js, ai-providers.jsx, mcp-configs.js, docs-registry.jsx
│       └── views/         Landing, SubPages, DocsView, ErrorPage, Auth, Overview, Trackers,
│                          Goals, Fapless, VoiceCoach (Speak), Social, CoachView, Settings
├── docs/                  ← you are here
├── screenshots/           before/after product shots used by the README
├── Showcase/              feature showcase captures
├── LICENSE.md             proprietary license
├── CONTRIBUTING.md        internal contribution workflow
├── LEGAL.md               legal notices, third-party licenses
└── SECURITY.md            vulnerability disclosure policy
```

## In-app documentation surface

The website mirrors the user-facing parts of these docs at `/docs`, `/docs/mcp`
and `/docs/ai-coach` (source: `frontend/src/views/DocsView.jsx`). When you change
MCP tool sets, provider lists or setup steps, update **both** this folder and
`DocsView.jsx` — plus the FAQ mirror in `frontend/index.html` (JSON-LD) and
`frontend/src/views/SubPages.jsx` if copy changes.
